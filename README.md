# Sorteio

Roda de sorteio para escolher um nome ao acaso.

## Como rodar

```bash
uv run sorteio
```

A interface abre em `http://127.0.0.1:8000`. Adicione os nomes, confira a lista e clique em **Sortear**.

Em uma hospedagem estática, a página inicial abre a roda direto. Os ganhadores ficam salvos no navegador.
